# Angular Signals menggantikan banyak kebutuhan RxJS untuk state lokal

Signal adalah nilai reaktif sinkron; `computed()` menurunkan nilai, `effect()` untuk side effect.

## Mengapa Penting
State komponen jadi lebih sederhana dan change detection lebih efisien (zoneless-ready).

## Tautan
- Berkaitan dengan [[Angular 20]] karena Angular 20 menstabilkan API signal.
